# 小鱼知识库问答系统

> 基于 **LangChain** 的企业级 RAG(检索增强生成)知识库问答系统
> 面向电商平台商品知识库 —— 用户在浏览器中提问,AI 依据知识库作答,**并展示回答引用了哪些原文片段**

前后端分离 · 本地私有化部署 · 开箱即用

---

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🤖 **知识库问答** | 基于 RAG 的商品问答,回答自动标注 `[1][2]` 引用来源 |
| 📑 **引用溯源** | 展示引用的原文片段、来源文档、页码、相关度,可展开查看 |
| 🔍 **检索过程可视化** | 显示每段资料来自"语义检索第 N 名"还是"关键词检索第 N 名" |
| 💬 **多会话管理** | 每个用户独立的会话列表;新建 / 切换 / 重命名 / 删除 |
| 🕐 **历史持久化** | 会话记录存数据库,随时登录随时找回 |
| 🧠 **多轮对话** | 自动改写问题(把"它的屏幕多大"补全为完整问题),追问不乱 |
| 👤 **用户系统** | 注册 / 登录 / 修改密码,JWT 令牌鉴权,bcrypt 密码加密 |
| 🔐 **权限隔离** | 管理员专属知识库管理与数据看板,前后端双重校验 |
| 📚 **知识库管理** | PDF / Word / Excel / CSV / TXT / Markdown 上传、异步解析入库、进度反馈、失败重试 |
| 📊 **数据看板** | 用户数、提问量、Token 消耗、7 天趋势、缓存命中率、好评率 |
| 👍 **回答反馈** | 点赞 / 点踩,收集质量数据 |
| 📤 **对话导出** | 一键导出为 Markdown(含引用来源清单) |
| 🌙 **深色主题** | 浅色 / 深色一键切换,设置自动记忆 |

## 🏗 技术栈

**后端**:Python 3.11 · FastAPI · LangChain 1.x · SQLAlchemy 2.x(异步)· SQLite · ChromaDB

**前端**:React 19 · TypeScript · Vite · Ant Design 6 · Zustand

**AI 能力**(阿里云百炼 DashScope):
- 对话生成:`qwen-plus`
- 文本向量化:`text-embedding-v4`(1024 维,实测)
- 重排序:`qwen3-rerank`

## 🔬 核心技术实现

### RAG 检索流水线(三道工序)

```
用户提问
   ↓
① 查询改写 —— 用 LLM 把依赖上下文的问题补全为独立问题
   ↓
② 混合检索 —— 向量检索(语义)+ BM25 关键词检索(精确)
   │              ↓
   │          RRF 融合排序(两路都靠前的胜出)
   ↓
③ 重排序 —— qwen3-rerank 逐条打分,精选最相关的 4 条
   ↓
④ 流式生成 —— qwen-plus 边生成边推送,标注 [1][2] 引用
```

### 实验数据(10 道标准测试题)

| 方案 | 命中率 | MRR(排名质量) | 平均耗时 |
|---|---|---|---|
| 纯向量检索 | 100% | 0.658 | 0.17s |
| 混合检索(向量 + 关键词) | 100% | 0.875 | 0.24s |
| **混合检索 + 重排序(本系统)** | 100% | **1.0** | 0.51s |

> MRR 越接近 1 表示正确答案排得越靠前。本系统可将正确答案稳定排在第 1 位。
> 完整报告见 [`docs/检索质量评估报告.md`](docs/检索质量评估报告.md)

### 企业级优化清单

| 优化项 | 做法 | 效果 |
|---|---|---|
| SSE 流式输出 | 边生成边传输 | 首字延迟 < 1 秒 |
| 混合检索 + RRF | 向量与关键词互补 | 召回更全,精确词不漏 |
| 重排序 | qwen3-rerank 精排 | 正确答案排名第 1 |
| 查询改写 | LLM 补全指代 | 多轮追问准确 |
| 问答缓存 | TTL + LRU,知识库变动自动失效 | 实测 3.49s → **0.06s**,零成本 |
| 异步任务队列 | 上传即返回,后台串行处理 | 大文件不阻塞,进度可视 |
| 全异步架构 | FastAPI + aiosqlite + 异步 LLM 调用 | 多用户并发不阻塞 |
| 接口限流 | slowapi 按用户限频 | 防恶意刷额度 |
| 全链路日志 | loguru 按天切分 | 问题可追溯 |
| 成本统计 | Token 用量记录 + 看板 | 成本可视化 |

## 🚀 快速开始

### 环境要求

- Python 3.11+、Node.js 20+
- 阿里云百炼 API Key([获取地址](https://bailian.console.aliyun.com/))

### 一、配置密钥

复制 `backend/.env.example` 为 `backend/.env`,填入你的密钥:

```ini
DASHSCOPE_API_KEY=sk-你的密钥
```

### 二、启动(Windows 一键启动)

双击项目根目录的 **`start.bat`**,浏览器会自动打开 http://localhost:5173

<details>
<summary>手动启动方式(点击展开)</summary>

```bash
# 终端 1:后端(端口 8000)
cd backend
venv\Scripts\python.exe run.py

# 终端 2:前端(端口 5173)
cd frontend
npm run dev
```
</details>

### 三、登录使用

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理员 | admin | 123456 |
| 普通用户 | 自行注册 | — |

### 四、准备知识库

管理员登录后进入「知识库管理」,上传商品资料即可。
项目自带 7 份演示资料(在 `sample_kb/` 目录),也可以用脚本一键生成并上传:

```bash
cd backend
venv\Scripts\python.exe tools\make_samples.py    # 生成样例文档
venv\Scripts\python.exe tools\rebuild_kb.py      # 清空并重建知识库
```

## 🔒 安全与隐私

- API 密钥存放于 `backend/.env`,已排除在版本库之外,不会上传
- 用户密码使用 **bcrypt** 加密存储(不可逆),数据库泄露也无法还原
- 登录使用 **JWT** 令牌;所有会话接口校验归属权,用户只能访问自己的数据
- 接口限流防止恶意刷取 API 额度
- 知识库文档与向量数据仅存于本机 `data/` 目录,不上传任何第三方存储
