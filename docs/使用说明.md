# 小鱼知识库问答系统 · 使用说明书

> 这份说明写给不熟悉编程的使用者,照着做就行。

## 一、怎么启动系统

### 方法一:双击启动(推荐)

打开项目文件夹 `D:\appserv\LangChainRAG项目`,**双击 `start.bat`**。

会弹出两个黑色的命令行窗口(一个是后端、一个是前端),**不要关闭它们**。
大约 12 秒后,浏览器会自动打开系统页面。

### 方法二:手动启动

如果双击没反应,可以手动敲命令(在项目文件夹里右键 → 在终端中打开):

```bash
# 第一个窗口:启动后端
cd backend
venv\Scripts\python.exe run.py

# 第二个窗口:启动前端
cd frontend
npm run dev
```

然后浏览器访问:**http://localhost:5173**

### 怎么关闭

关掉那两个黑色窗口即可停止服务。下次要用再双击 `start.bat`。

## 二、怎么使用

### 1. 登录

| 角色 | 账号 | 密码 | 能做什么 |
|---|---|---|---|
| 管理员 | admin | 123456 | 提问 + 管理知识库 + 看数据看板 |
| 普通用户 | 自己注册 | 自己设置 | 只能提问 |

首次使用可以点"注册"标签自己注册一个普通账号,体验普通用户的视角。

### 2. 提问(核心功能)

在"智能问答"页面底部的输入框里打字,**按 Enter 发送**(Shift+Enter 是换行)。

- 回答会一个字一个字地显示出来(打字机效果)
- 回答里的 **`[1]` `[2]`** 蓝色标签表示"这句话的依据来自第几份资料"
- 回答下方有 **"参考资料"** 折叠区,点开能看到原文,以及"语义检索第几名""关键词检索第几名"
- 每条回答下面可以点 👍 或 👎

**试试这几个问题:**
- 星辰X1手机的电池容量是多少?
- 七天无理由退货的运费谁承担?
- 星辰Book 16 Pro 的屏幕分辨率是多少?

**试试多轮追问**(系统会自动理解"它"指的是什么):
- 先问:"星辰Book 16 Pro 卖多少钱?"
- 再问:"它的屏幕多大?"
- 再问:"那电池呢?"

### 3. 管理会话

- 左上角 **"新对话"**:开一个新的聊天窗口
- 点击左侧会话列表:**切换**到那个会话,历史记录自动加载
- **双击**会话标题:**重命名**
- 鼠标移到会话上,点**垃圾桶图标**:删除
- 右上角 **"导出对话"**:把整段对话存成文件(可用记事本打开)

### 4. 管理知识库(仅管理员)

左侧菜单 → **知识库管理**:

- **上传资料**:把 PDF / Word / Excel / TXT / Markdown 文件拖进虚线框(可一次拖多个)
- 上传后会自动处理:排队中 → 处理中(有进度条)→ 已完成
- 处理失败会显示原因,点 ↻ 可以重新处理
- 点垃圾桶可以删除文档(它的知识卡片会一并清除)

### 5. 查看数据看板(仅管理员)

左侧菜单 → **数据看板**:这里能看到注册用户数、提问次数、AI 额度消耗、
最近 7 天的活跃度柱状图、缓存命中率、回答好评率。

### 6. 更换主题 / 修改密码 / 退出

右上角:

- 🌙/☀️ 图标:切换深色 / 浅色模式
- 点自己的用户名:弹出菜单 → 修改密码 / 退出登录

## 三、常见问题

### 提问时提示"阿里云账户余额不足"

说明阿里云百炼的免费额度用完了。请登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/) 查看额度并充值。
充值后**重新启动后端**(关掉黑色窗口再双击 start.bat)即可恢复。

> 参考价格:qwen-plus 约 1 元 / 百万字,日常演示用几块钱就够很久。

### 提示"无法连接后端服务"

后端没启动或已关闭。检查那个黑色窗口是否还在,不在就重新双击 `start.bat`。

### 启动时提示"端口被占用"

说明上次的服务还在后台运行。打开任务管理器,结束所有 `python.exe` 和 `node.exe` 进程,再重新启动。

### 上传的文件一直显示"处理中"

大文件(比如几十兆的 PDF)需要几分钟,耐心等待即可。如果超过 10 分钟仍在处理中,
可以关掉后端重新启动(系统会自动把没处理完的任务重新排队)。

### 想换一个更聪明的 AI 模型

打开 `backend\.env` 文件,把 `LLM_MODEL=qwen-plus` 改成 `LLM_MODEL=qwen-max`(能力更强但更贵),
保存后重启后端即可。

## 四、文件位置速查

| 内容 | 位置 |
|---|---|
| 用户上传的原始文件 | `data\uploads\` |
| 知识库数据(向量库) | `data\chroma\` |
| 账号与会话数据 | `data\app.db` |
| 运行日志 | `logs\` |
| 演示用的商品资料 | `sample_kb\` |
| 阿里云密钥配置 | `backend\.env`(**不要外传**) |
